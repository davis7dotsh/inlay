Inlay 1.0 is the first public release. Hold a key, speak, and release to insert your dictation into any Mac app. A native Swift client talks to a self-hosted model server that runs on the same Mac, another Mac, or a Linux box with or without an NVIDIA GPU. Speech recognition uses Parakeet TDT 0.6B v3, and Qwen3-4B-Instruct-2507 cleans up the transcript. Audio and history stay on machines you control.

## Install on a Mac

Requires Apple Silicon and macOS 14 or later.

1. Download `Inlay.dmg`. Optionally check it with `shasum -a 256 -c Inlay.dmg.sha256` from the download folder.
2. Open the DMG and drag **Inlay** to **Applications**. The app is signed with Developer ID and notarized by Apple.
3. Open Inlay. Under **This Mac**, download the pinned models (about 4 GB) and install the bundled local server. It runs as a per-user LaunchAgent on `127.0.0.1:8391`.
4. Grant Microphone and Accessibility. On macOS 27 and later, the Accessibility list is **Privacy & Security → Device Control and Data Access**.
5. Focus a text field, hold **Fn/Globe**, speak, and release.

## Run the server on another machine

| Asset                                 | Host                                                                   |
| ------------------------------------- | ---------------------------------------------------------------------- |
| `inlay-server-darwin-arm64.tar.gz`    | Apple Silicon Mac, macOS 14+ (the same notarized server as in the DMG) |
| `inlay-server-linux-x64-cpu.tar.gz`   | Linux x86_64, CPU only                                                 |
| `inlay-server-linux-arm64-cpu.tar.gz` | Linux ARM64, CPU only                                                  |
| `inlay-server-linux-x64-cuda.tar.gz`  | Linux x86_64 with an SM 80+ NVIDIA GPU and driver 580.95.05 or newer   |

```sh
shasum -a 256 -c inlay-server-linux-x64-cuda.tar.gz.sha256
sudo mkdir -p /opt/inlay
sudo tar -xzf inlay-server-linux-x64-cuda.tar.gz -C /opt/inlay --strip-components=1 --no-same-owner
```

Each tarball contains a `server` directory with the standalone `inlay-server` executable, native helpers, the Silero VAD model, and on Linux an `inlay-server.service` unit. Model weights download separately. Follow the [server guide](https://github.com/davis7dotsh/inlay/blob/v1.0.0/Server/README.md) for models, systemd setup, and HTTPS or Tailscale access. Then enter the server URL and token under **This Mac** in the app.

## Highlights

- Parakeet TDT 0.6B v3 speech recognition across 25 European languages, with Qwen proofreading, shared dictionary entries, and editable cleanup instructions.
- Audio uploads while you speak. Finished recordings queue on the server, so you can start the next take immediately.
- One server, many Macs: history and shared preferences sync across connected clients, tagged by device.
- Server packages for Apple Silicon (Metal and MLX), Linux CPU on x86_64 and ARM64, and a statically linked CUDA build.
- Hold-to-talk or double-tap toggle, an option to mute system audio while recording, and an option to never leave transcripts on the clipboard.
- More reliable insertion: Electron apps get their accessibility tree prepared, Edit → Paste is found even when other menus are slow to read, and multichannel USB microphones work.
- Import local Wispr Flow history.

## Upgrading from a source build

The client and server must both speak API version 4. Update them together. Existing Whisper weights fail the Parakeet pin; download the new model with `scripts/download-model.sh`. See [upgrade an existing installation](https://github.com/davis7dotsh/inlay/blob/v1.0.0/README.md#upgrade-an-existing-installation).
